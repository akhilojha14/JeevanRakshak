# JeevanRakshak 🚨

**A web-based emergency assistance dashboard designed to make emergency actions easier to access.**

## 🌟 Features

- 📞 Quick access to India's emergency number (112)
- 📍 Get the user's location using browser geolocation
- 🏥 Find nearby hospitals using Google Maps
- 📝 Create an emergency message with location details
- 📋 Copy or share the emergency message
- 📱 Responsive interface for desktop and mobile

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser Geolocation API
- Google Maps links
- Web Share API

## 🚀 Run Locally

1. Clone this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server, or run:

   ```bash
   python3 -m http.server 8000
   ```

4. Open `http://localhost:8000` in your browser.

## ⚠️ Disclaimer

JeevanRakshak is a prototype for emergency assistance. It does not automatically dispatch an ambulance, contact emergency services, or guarantee a response. For an actual emergency in India, call **112** directly.
